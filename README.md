# eki-play — 日本铁路车站周边指南（観光名所 / 名所案内 / 便民公共服务）

**ja · en · zh 三语并列**的车站周边便民数据，基于 `ooep/eki-wiki`（577 条线路 / 16,955 座车站）逐站构建。

## 每站提供什么

| 分区 | 内容 | 主要来源 |
|---|---|---|
| 観光・名所案内 | 观光景点、历史文化设施、观景点、博物馆、公园 | OSM(Japan) POI、日文维基百科站条目 |
| 文化・公共施設 | 图书馆、美术馆、公会堂、体育场 | OSM、维基 |
| 買い物・商店街 | 商店街、超市、便利店 | OSM |
| 便民公共服务 | 警察、邮局、区政府、医院、药局、银行、ATM、观光案内所 | OSM、维基 |
| 交通接続 | 公交站、出租车乘车处、共享单车、换乘车站 | OSM |
| 宿泊 | 酒店、旅馆 | OSM |

每条记录带：**日文名**、**英文名**、**中文名**、类别、距车站的直线距离、**官网链接**、**维基百科链接**、以及原文引用出处。

## 数据来源与授权

- **OpenStreetMap**（日本抽取，Geofabrik `japan-latest.osm.pbf`）— © OpenStreetMap contributors, **ODbL 1.0**。用于 POI 名称、类别、坐标、距离、`name:en`/`name:zh`/`website`/`wikipedia` 标签。
- **维基百科（日文/英文/中文）** — **CC BY-SA 4.0**。用于车站条目「駅周辺」原文、景点正文与链接。
- **Wikidata** — **CC0**。用于官网、多语言标签、实体识别。
- 各设施**官网**由上述来源中的 `website` / 维基外部链接取得，并在入库前做 HTTP 可达性校验（校验结果与抓取日期记录在 `docs/SOURCES.md`）。

> ⚠️ 重要说明：本仓库为**自动化数据管线**产出，非人工撰写旅游指南。数据覆盖度与翻译完成度**逐站不同**，一律以每条记录的 `出典`／`sources` 字段为准。未翻译字段保留 `null`，不做机器填充。详见 `docs/COVERAGE.md`。

## 二層構造 / 两层结构 / Two tiers

1. **自動層 `data/lines/`** — 全 577 线路 × 16,955 站的周边设施，来自 OSM 点与面（公園・城跡・寺院境内等の polygon 重心を含む）＋日文维基百科「駅周辺」リンク。每条记录带 `来源` 出典。

## 座標の同定と検証 / 坐标定位与校验 / Coordinate QA

周边设施全部按**车站坐标**计算距离，因此坐标正确性优先于数量。产出后做了五轮校验（过程与失败记录见 `docs/SOURCES.md`）：

1. **OSM 駅ノード照合** — 大多数の駅はこれで確定。`位置.坐标.出处` にノードIDを残す。
2. **後補座標** — 表記差（ヶ⇄ケ 等）で一致しなかった駅は、日本語版ウィキペディア記事→Wikidata P625 または記事自身の座標で補完し、`位置.坐标来源` に出典。
3. **線内分布テスト（方式差し替え）** — 初回は「中央値＋パーセンタイル」、次いで「30 km 単連結クラスタ」を試みましたが、いずれも失敗しています（前者は混入駅が閾値を自己膨張させて失明、後者は駅間 30 km 超の新幹線・長距離線で東京駅等を誤検知）。採用したのは **`linegap.py` の最近傍ギャップ test**＝「同一ファイル内で最も近い他駅までの距離」で、100 km 超を遠方同名駅の疑いとして 30 駅を判定。うち 23 駅は路線内の隣接駅中央値×3（10-40 km）＋半径内 2 駅以上の裏付けという条件で同名ノードへ差替え（`位置.坐标修正` に旧値・距離・判定）、7 駅は座標を動かさず `線外疑い` としました。
4. **線外疑いフラグ** — 差替え根拠が無い駅は座標を変更せず `データ品質.座標 = "線外疑い"` を付与（現 42 駅）。消費側はこれで除外できます。

```python
ok = [s for s in d['车站'] if s['データ品質'].get('座標') != '線外疑い']
```

## 目录结构

```
data/lines/<线路名>.json      每条线路一个文件，内含该线路全部车站的三语周边数据
data/curated/<区域>/<駅>.json 重点车站加精层（人手検索 / 自動抽出＋出典検証 を明示）
schema/station.schema.json    数据字段定义
scripts/                      生成・検証パイプライン（OSM索引→路線生成→三語補強→座標検証→加精→docs）
docs/CURATION.md              加精层的产出规范（10 条硬性规则）
docs/SOURCES.md               来源、坐标校验过程（含失败记录）、复现命令
docs/COVERAGE.md              覆盖率统计（逐语言 / 逐分区 / 加精层）
index.json                    全站统计サマリ（线路一覧・件数・充足率）
```

`scripts/` は再現用。スクリプトはビルド環境の `/data/osm`・`/data/eki-wiki`・`/data/eki-play` を前提パスとしていますが、パスは冒頭の変数で変更できます。認証情報はリポジトリに含みません（`gitx.sh` は外部トークンファイルを読むだけで、トークン自体は格納していません）。

## 使用

```python
import json
d = json.load(open('data/lines/山手線.json', encoding='utf-8'))
for st in d['车站']:
    print(st['名称']['日文'], st['位置']['坐标'])
    for item in st['分区']['観光・名所案内']:
        print('  ', item['名称']['日文'], item['距车站m'], item.get('官网'))
```
